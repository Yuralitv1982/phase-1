Уровеньень 2:** Продвинутый Новичок (Advanced Beginner) — Работа с множеством
* 🎯 **Фокус:** Массовые операции (Wildcards), скрытые файлы, безопасность удаления.

* 💻 **Настройка окружения:** В корне project-alpha создать скрытые файлы конфигурации: .env, .gitignore, .editorconfig. Убедиться, что они созданы, выведя полный список файлов (включая скрытые) с детальной информацией (права, размер).

* 💻 **Сортировка модулей:** Создать папку src/js. Переместить все файлы с расширением .js из src в src/js одной командой.

* **Безопасное удаление:** Попытаться удалить папку src. Система должна запросить подтверждение для каждого файла внутри. (Если система удалила молча — вы провалили задачу, нужно было использовать безопасный флаг).

* 🎯 **Чтение документации:** Создать файл README.md с текстом (любым, 10-15 строк). Вывести в терминал только первые 3 строки этого файла. Затем вывести только последние 3 строки.

* 💻 **Поиск потерянного:** Найти в дереве папок все файлы с расширением .json. Путь должен быть выведен от корня проекта.
