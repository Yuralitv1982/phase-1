# Модуль 1: Дешифровка навигации и манипуляций

## 1. Навигация («Где я и как выйти?»)

* pwd — Print Working Directory.

* **Перевод:** «Распечатай рабочую директорию». Команда-маяк. Она просто говорит: «Ты находишься здесь».

* ls — List.

* **Перевод:** «Список». Как ты и угадал, это просто оглавление текущей папки.

* cd — Change Directory.

* **Перевод:** «Сменить директорию». Твой телепорт между папками.

## 2. Создание и удаление («Стройка и снос»)

* mkdir — Make Directory.

* **Перевод:** «Создать директорию». Инженерный глагол: создать контейнер.

* rmdir — Remove Directory.

* **Перевод:** «Удалить директорию». Работает только с пустыми папками (защита от дурака).

* touch — Touch.

* **Перевод:** «Коснуться». Очень странное название, но логичное: если файла нет, ты «касаешься» пустого места и он появляется. Если есть — ты просто обновляешь дату его последнего изменения.

* rm — Remove.

* **Перевод:** «Удалить». Тот самый «ластик», который в связке с флагом -rf (recursive force) может стереть всю систему, если не дружить с головой.

## 3. Манипуляции («Грузчики»)

* cp — Copy.

* **Перевод:** «Копировать». Дублирование сущности.

* mv — Move.

* 🛠️ **Перевод:** «Переместить». В Linux это же команда и для переименования. Логика такая: переместить файл из старое_имя в новое_имя в той же папке.

## 4. Просмотр содержимого («Чтение документации»)

* cat — Concatenate.

* **Перевод:** «Сцепить/Соединить». Изначально команда была нужна, чтобы склеивать несколько файлов в один, но все её используют, чтобы просто вывалить содержимое файла в терминал.

* less / more.

* **Тут консольный юмор:** Раньше была команда more (еще), которая позволяла читать текст по одной странице. Потом написали более продвинутую и назвали её less (меньше), потому что в мире Unix «less is more» (меньше — значит больше).

* head / tail.

* **Перевод:** «Голова» и «Хвост». Выводят первые или последние 10 строк файла. Для архитектора tail -f (follow) — это главный инструмент, чтобы смотреть, как пишутся логи сервера в реальном времени.

## 1. Команда ls (List) — Список файлов

* 💻 **ls --all (вместо -a):** Показать всё (All). Включает скрытые файлы типа .env или .gitignore. Без этого флага ты их просто не увидишь.

* **ls --long (вместо -l):** Длинный (Long) формат. Выводит таблицу с правами доступа, владельцем, размером файла и датой изменения.

* **ls --human-readable (вместо -h):** Включается только вместе с --long. Показывает размер в человеческих единицах (Кб, Мб, Гб), а не в безликих байтах.

* **ls --recursive (вместо -R):** Рекурсивно. Покажет файлы не только в этой папке, но и во всех вложенных.

## 2. Команда mkdir (Make Directory) — Создать папку

* **mkdir --parents (вместо -p):** Создать родителей (Parents).

* 🏗️ **Пример:** Если тебе нужна структура src/api/v1, а папок src и api еще нет, обычная команда выдаст ошибку. С этим флагом Bash создаст всю цепочку.

## 3. Команда rm (Remove) — Удалить

* **rm --recursive (вместо -r):** Рекурсивно. Удаляет папку и всё, что внутри неё. Без этого флага rm умеет удалять только одиночные файлы.

* **rm --force (вместо -f):** Силой (Force). Игнорировать несуществующие файлы и никогда не спрашивать подтверждения. «Делай, что сказано, и не ворчи».

* ⚡ **rm --interactive (вместо -i):** Интерактивно. Перед каждым удалением будет спрашивать: «Точно?». Полезно, когда рука дрожит.

## 4. Команда cp (Copy) — Копировать

* **cp --recursive (вместо -r):** Копировать всю папку со всем содержимым.

* **cp --preserve (вместо -p):** Сохранить (Preserve). Копирует файл так, чтобы у копии остались те же дата создания и права доступа, что и у оригинала.

## 5. Команда grep — Поиск текста

* **grep --ignore-case (вместо -i):** Игнорировать регистр. Поиск найдет и "ERROR", и "error", и "Error".

* **grep --invert-match (вместо -v):** Инвертировать совпадение. Покажет все строки, где нет искомого слова. Отлично для фильтрации лишнего мусора из логов.

* **grep --recursive (вместо -r):** Искать текст во всех файлах внутри папки.

* Визуальная шпаргалка по анатомии команды
* Рецепт «Безопасное удаление» (из концепции системного администрирования)

* 🇬🇧 Архитекторы часто используют связку --verbose, чтобы видеть, что именно делает команда в данный момент.

* Snippet:
* 🛠️ Bash

* # Удалить папку со сборкой и показать список всех удаленных файлов
* 🇬🇧 rm --recursive --force --verbose dist/

* 🇬🇧 --verbose — Многословно. Команда будет «отчитываться» о каждом шаге. Если файлов тысячи, ты увидишь их список в терминале.

2. less (Интерактивное чтение)

Даже если у тебя bat, он по умолчанию часто использует less как «пейджер» (инструмент для прокрутки).

Зачем он нужен: Если лог-файл твоего Node-сервера весит 100 Мб, bat или cat попытаются вывалить его весь в память и терминал. Система «поперхнется». less открывает файл по кусочкам.

Кнопки-инстинкты в less:

    /слово — поиск по тексту.

    n — следующее совпадение (next).

    N — предыдущее совпадение.

    G (большая) — прыгнуть в самый конец файла (увидеть свежие записи).

    g (маленькая) — прыгнуть в начало.

    q — выход (Quit).

3. head и tail (Голова и Хвост)

Эти утилиты — хирургические инструменты. Они берут только кусок данных.

    head --lines 20 file.json — посмотреть «шапку» конфига, чтобы понять структуру.

    tail --lines 50 app.log — посмотреть последние 50 ошибок.

Главный инструмент Node-разработчика: tail --follow (или -f)

Эта команда не закрывается. Она держит файл открытым и «выплевывает» новые строки сразу, как только Node.js их туда записал.
