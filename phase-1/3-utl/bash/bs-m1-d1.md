# Уровень 1: Новичок (Novice) — Механика и Структура

* 🎯 **Фокус:** Ориентация в файловой системе, создание «скелета» проекта.
* 

* 🛠️ **Проектирование структуры:** Создать в домашней директории дерево каталогов learning-linux/project-alpha. Внутри project-alpha создать три папки параллельно: src, dist, config.
* 

* 💻 **Генерация ассетов:** В папке src создать 5 пустых файлов: index.js, style.css, logo.png, utils.js, api.js.
* 

* ⚡ **Рефакторинг путей:** Переименовать папку dist в build.
* 

* 💻 **Бэкап конфигурации:** В папке config создать файл settings.json. Сделать его копию в той же папке с именем settings.json.bak.
* 

* ⚡ **Чистка:** Удалить файл logo.png (как неиспользуемый ассет) и удалить пустую папку build (как артефакт, который пересоздается).
*
